## Key Features

<CardGrid stagger>
  <Card title="100% Native Rust" icon="rocket">
    Ultra-optimized architecture across 21 modular Rust crates with zero runtime Python passthrough. Sub-millisecond search latencies and self-contained binaries.
  </Card>
  <Card title="Tripartite Memory Model" icon="puzzle">
    Seamlessly combines **episodic** (JSONL events & sessions), **semantic** (Markdown vault notes & graph), and **procedural** (rules & ActionEngine) memory.
  </Card>
  <Card title="Hybrid Search with RRF" icon="magnifier">
    Fusion of native BM25 lexical search and ONNX cosine vector similarity via *Reciprocal Rank Fusion*, guaranteeing the most relevant retrieval.
  </Card>
  <Card title="Local ONNX Inference" icon="laptop">
    Generates embeddings directly on your machine using `ort` and local ONNX models (`all-MiniLM-L6-v2`). Zero external API calls for indexing.
  </Card>
  <Card title="Built-in MCP Server" icon="setting">
    32 Model Context Protocol tools natively announced for Claude Code, Cursor, Pi IDE, Windsurf, Codex, and Antigravity.
  </Card>
  <Card title="Enterprise Governance" icon="approve-check-circle">
    Knowledge review queues, promotion pipelines, audit trails, and configurable team retention policies.
  </Card>
</CardGrid>
