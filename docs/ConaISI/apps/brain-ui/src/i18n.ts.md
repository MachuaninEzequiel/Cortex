# apps/brain-ui/src/i18n.ts

## Qué tiene adentro

Diccionario `translations.es` / `translations.en` para chrome: topBar, sidebar, chat, statusBar, settings (modelo, paths, atajo, about), toolModal, doctor, org memory, webgraph.

`getT(lang)` selecciona el bloque.

## Para qué sirve

UI bilingüe de la app desktop (independiente de `cortex-brain::i18n`, que es el chrome del binario CLI).

## Relaciones

### Recibe de

- `Lang` de `types.ts`

### Envía a

- components vía `getT(lang)`

### Notas de implementación observadas en el código

Claves anidadas por pantalla. Tema descrito como Catppuccin Mocha.
