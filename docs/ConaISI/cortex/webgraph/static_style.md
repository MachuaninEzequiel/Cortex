# cortex/webgraph/static/style.css

## Qué tiene adentro

CSS de la UI WebGraph: fondo en degradés, `.shell` max 1360px, grid `.workspace` (canvas 1.8fr + detalle ~280px), paneles blancos translúcidos, tipografía Segoe UI, color texto `#183045`.

## Para qué sirve

Presentación visual del grafo. Sin lógica.
