## Para qué sirve

cortex.setup.templates
----------------------
Template system for files generated by ``cortex setup``.

Generates project-aware defaults for:
- config.yaml
- GitHub Actions workflows (ci-feature, ci-pull-request, cd-deploy)
- Vault starter docs (architecture, decisions, runbooks)
- devsecdocops.sh script
