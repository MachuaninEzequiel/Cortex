# rust/crates/cortex-brain/src/i18n.rs

## Qué tiene adentro

Chrome bilingüe ES/EN del brain.

- `Lang { Es, En }` con `parse` (cualquier valor no-`en` → Es) y `code`
- Estado global `RwLock<Lang>`: `fijar` / `actual`
- Textos: `ayuda`, `no_ejecutado`, `tool_inexistente`, `hasta_proxima`, `cargando_gguf`, `sugerencia`, `prompt_confirmar`, `backend_line`, warnings de modelo/llama/args/ventana
- Capa tools: `falta_query`, `related_precision`, `vault_stats`, `webgraph_ok` (puerto `http://127.0.0.1:8000`), `tool_desconocida`, errores CLI, textos de `actions.propose`
- `leer_ui_language`: mini-escáner YAML de `ui.language` (sin crate yaml)
- `detectar(env, nueva, legacy)`: `CORTEX_LANG` válido > `.cortex/config.yaml` > `config.yaml` > `Es`. Env basura no fuerza idioma.

## Para qué sirve

Traducir solo el chrome (help, prompts, avisos). Salidas del CLI y patrones del router no se traducen aquí.

## Relaciones

### Recibe de

- env `CORTEX_LANG`
- archivos YAML de config
- callers (`main`, `tools`, `chat`)

### Envía a

- strings a stdout / errores de dispatch

### Notas de implementación observadas en el código

Config rota no rompe UI (fallback Es). Tests cubren parse, layout `ui.language`, comillas/comentarios, prioridad env.
